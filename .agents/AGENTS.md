# Project Rules - Foyer Rural d'Esnoms au Val

## Versioning & Release Summary Rule
For EVERY modification or bug fix made to the codebase:
1. Increment the version number across `sw.js`, `manifest.json`, `index.html`, and `app.js`.
2. ALWAYS update the static version badge AND description text in `index.html` (under **Paramètres & Configuration Firebase** -> **Version & Dernières Modifications**) with:
   - The new version number (e.g. `v7.1`).
   - The current date (e.g. `12 août 2026`).
   - A clear, concise summary of the latest modification or fix.
