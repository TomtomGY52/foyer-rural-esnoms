Sauvegarde des Données (Local)

En mode local, vos données sont enregistrées dans le cache de votre navigateur. Vous pouvez exporter vos données sous forme de fichier JSON ou importer une sauvegarde précédente.

Configuration Firebase / Cloud

Connectez votre application à Firebase Firestore pour activer la synchronisation en temps réel et y accéder sur votre smartphone ou d'autres appareils.

Obtenez le classeur Excel officiel pré-formaté (4 onglets : Transactions, Adhérents, Manifestations et Investissements) avec des colonnes explicites et des données d'exemple.

2 Déposer le Fichier Excel Rempli
